## [Unreleased]

### Added

- Apache-2.0 repository skeleton, community and security documents.
- Tauri 2 / Rust workspace and Svelte 5 / TypeScript application shell.
- Six resizable dividers with minimum sizes and keyboard support; Light CSS tokens.
- Rust smoke test, Splitter size tests, and three-platform CI configuration.
- Real Git filename fixtures for Unicode, spaces, leading dashes, and Unix tab/newline names.
- macOS universal DMG artifact workflow with ad-hoc signing and SHA-256 checksums;
  Windows and Linux release jobs reserved for v0.2.
